# Image Recognition and Translation Web Application

## Project Overview
This project is a web application developed using Flask. It combines object detection and image processing with translation functionality.

## Technologies
- Python
- Flask
- OpenCV
- YOLOv8m
- Google Translator

## Main Features
- Image recognition and object detection
- Image processing using OpenCV
- Text translation using Google Translator
- Web-based user interface
- Mobile camera access testing

## Development
The application was developed using Python and Flask. YOLOv8m was used for object detection, while OpenCV handled image processing.

The web application was also tested on an iPhone through an ngrok connection.
